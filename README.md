# Nova Studio — downloads & updates

Live church production by **Code The Web**.

**Download:** open **[Releases](../../releases/latest)** and run `Nova-Studio-Setup-x.y.z.exe` (Windows 10 / 11, 64-bit).

Installed copies update themselves from here: Nova Studio checks in the background, downloads quietly, and installs only when the app is closed — never during a live service or recording.

This repository holds the installers only.
